# 设置

用 **OK**、**8**，或 **\***、**0** 打开设置。设置按用途分组。数字键直接打开某个分组；**电台信息**位于第 9 组之后，没有编号，从顶部按 **上** 即可到达。**0** 打开查找，它也能按名称找到每项设置（与在主屏幕输入其开头字母相同）。

## 更改设置

每行显示当前值。页面的标题就是打开它的那一行。

- 开关设置用 **OK** 更改，该行显示新状态。
- 有多个取值的设置在按 **OK** 时打开选择列表，正在使用的值带勾号。用 **上** 或 **下**（或信道旋钮）选择，然后按 **OK** 采用，或按 **返回** 保持原样。
- 数字设置在按 **OK** 时打开数值编辑器：数值位于两个标记之间，使用外观的高亮颜色。用 **上** 和 **下**（或信道旋钮）更改数值，或用数字键输入，按 **OK** 保留，按 **返回** 保持不变。输入超出范围或位于步进之间的值不会被接受：电台显示“未更改”及范围。
- 设置一更改就生效并保存，没有单独的保存步骤。

<img src="../ux/screens/160x120i5/settings_pick.png" width="200" alt="选择列表">
<img src="../ux/screens/160x120i5/settings_editor.png" width="200" alt="编辑数字设置">

有些设置在其背后的功能存在之前就在菜单中，或对本电台不适用。它们会变暗。在变暗的行上按 **OK** 会说明原因。各表的状态列表示：

| 状态 | 含义 |
|---|---|
| 有效 | 立即生效，并在关机后保留 |
| 有效，不保留 | 立即生效，关机后恢复默认 |
| 变暗 | 尚未构建，或本电台没有。按 **OK** 说明原因 |

## 参考

设置有九个编号分组，之后是**电台信息**。有些分组为一组相关的行设有单独的页面：**音调与提示**中有**提示音**和**信令音**。位置、中继和电脑连接的设置位于这些功能所在之处：**菜单 > 位置 > 位置设置**、**菜单 > 连接 > SFR** 和**菜单 > 连接 > 电脑与网络**（见下文）。

### 写频（按键 9）

更改电台频率或电台本身的内容。**恢复出厂设置**是最后一行。

| 项目 | 作用 |
|---|---|
| 信道 | 按编号列出每个信道，首行为**用当前新建**（[信道](07-channels-zones-vfo.md#every-channel)） |
| 区域 | 区域列表，可在其中新建、重命名、复制和删除区域（[区域](07-channels-zones-vfo.md)）；与**菜单 > 区域**是同一个列表。仅用于含区域编辑的构建 |
| VFO | 切换到 VFO，或回到信道：与**菜单 > 区域**中的 VFO 行相同（[VFO](07-channels-zones-vfo.md#the-vfo)）。仅用于有 VFO 的电台 |
| DMR ID 和名称 | 先显示电台型号，然后是你的 DMR ID、电台名和两行启动文字，均按电台频率中的存储显示。在 **DMR ID** 上用数字键输入新 ID（最大 16776415；更大的 ID 预留给网络）并按 **OK**：电台会写入电台频率并立即使用，电台频率编辑器或 qdmr 下次读取时可见。**返回** 收回最后一位，全部收回后 ID 保持不变。在**电台名**、**启动 1** 或 **启动 2** 上，**OK** 打开文本输入（[文本输入](07-channels-zones-vfo.md#text-entry)）；其中的 **OK** 保存，最多 16 个字符 |

#### 位置

你的位置用于 DMR 通话（DMR 通话带位置）、调度员的位置请求（应答 GPS 请求）以及 APRS。它们互不依赖：没有 APRS 的电台仍可通过 DMR 报告位置。

- **自动**优先使用新的 GPS 位置，其次是电脑的位置，最后是固定位置。有定位时用**保存 GPS 位置**把当前坐标存为固定位置；重启后 GPS 尚在搜索时，电台即可使用它们。
- **GPS**、**电脑**和**固定**只使用对应的那一种。
- 含 APRS 的固件提供电脑选项，它通过 USB 读取电脑的 GPS（[APRS](13-aprs.md#position)）。
- 这些设置会保存，电台重启后仍在。

## 信令音

**设置 > 音调与提示 > 信令音**有三个事件，各有自己的音调：你发射的**开始**、发射的**结束**，以及接收结束、信道重新空闲的**空闲**时刻。DMR 和 FM 分别设置。对每个事件，你选择音调在哪里响起，并逐步自己编排音调。

**在哪里响起**（DMR 起始音、DMR 结束音、DMR 空闲音、FM 起始音、FM 结束音、FM 空闲音）：

| 输出 | 音调响起的位置 |
|---|---|
| 默认 | 与以前相同：通话许可音和通话结束音（其开关在 设置 > 音调与提示 > 提示音 中），以及 FM roger beep，它还没有菜单行（开发者通过调试链路开启，否则为关）。默认不是第五种位置：它表示“让该事件保持此设置出现之前的样子” |
| 关 | 从不，包括电台自身对该事件的提示音 |
| 扬声器 | 仅在你的扬声器上 |
| 空中发射 | 在你的发射中，让其他电台听到。DMR 以语音发送；FM 以载波上的音调发送 |
| 扬声器+空中 | 两者都有 |

空闲音没有“空中发射”选项：那时不会发送任何内容。空中发射的 FM 起始音在电台开始发射后、你的语音发出之前立即播放；松开 PTT 即停止。

**音调本身**是每个事件最多十步的序列，类似 CPS 提示音页面中的频率和周期行。**起始步骤**、**结束步骤**和**空闲步骤**这几行显示各序列有多少步（没有步骤时显示“标准”），并打开其十个步骤：

| 步骤 | 显示为 | 取值 |
|---|---|---|
| 频率 | `1570 Hz` | 0 到 3400，步进 10。0 为停顿 |
| 时长 | `40 ms` | 0 到 900，步进 10。0 结束序列：其后的步骤被忽略 |

要设置某一步，在其上按 **OK**，用键盘输入频率（`1 5 7 0`）或用上、下步进，按 **OK**，再以同样方式设置时长并再按一次 **OK**。**返回** 保持该步不变。不在步进上或超出范围的数字会被拒绝，提示会说明可用的值。原先关闭的步骤从 40 ms 开始。整个序列在 900 ms 处截断；步骤上方的一行显示目前的总时长。没有步骤时，该事件播放其**标准声音**（开始时为许可音，结束和空闲时为通话结束音）。FM 结束音是从菜单获得 roger beep 的方法：把它设为空中发射（或扬声器+空中）；要与 roger beep 完全一致，把结束步骤设为 1200 Hz 100 ms 和 900 Hz 100 ms。要复制每个 40 ms、依次为 0、1570、1050、1570 和 1320 Hz 的 CPS 呼叫音，把起始步骤 1 到 5 设为这些值对。最多十个音的五音或 ZVEI 式选呼也能这样设置：每个音一步，例如每个 70 ms。

- 这些音调也保存在电台频率中，因此电台频率编辑器在 **Radio > Signaling tones** 下显示它们，写入电台的电台频率也会设置它们。在编辑器中，每个事件为 **Not set**（电台保留自己的设置）或 **Set**，带两个输出和十个步骤。在电台菜单中所做的更改也会写入电台频率。
- 空中发射的起始音位于你的语音之前，语音会稍晚开始。空中发射的结束音在你松开 **PTT** 之后发出，电台会为它保持发射（最多约一秒），然后结束发射。
- 信道的**通话许可音**字段关闭时，该信道没有这些音调。
- 音调以语音编解码器的音调帧发送。稳定的音调传输良好；快速序列可能听起来粗糙，其他品牌的电台也可能播放得不同。依赖它之前，请用第二部电台试一试。
- 空中发射的结束音计入发射超时。
- 在发射时无法发出提示音的电台上，扬声器上的 DMR 起始音在电台开始发射之前播放。扬声器上的 FM 起始音来自电台自身的音调侧音（如果有）：音调发送的同时，你会听到它。没有侧音时，这类电台在扬声器上没有 FM 起始音。
- 输出为默认时，无论序列如何，总是播放电台自身的提示音：要使用序列，请选择扬声器、空中发射或两者。

## 崩溃日志

固件崩溃时，电台会保留一份简短记录，说明发生位置和原因，然后重启。停止响应约 3 秒的电台也算崩溃：记录显示“挂起”。**设置 > 写频 > 崩溃日志**显示该记录：发生了什么、连续崩溃次数、电台运行了多久以及固件构建。没有记录时显示“无崩溃记录。”关机可能会丢失记录：请先查看再关机。

## 没有菜单的设置

电台中有一些设置尚未出现在菜单中：

- 忙信道锁定和 roger beep；
- 扫描的恢复模式和时序；
- VOX 灵敏度；
- 紧急设置；
- IP 数据设置（头压缩、确认数据）和 SNMP 团体名；
- 漫游阈值、迟滞和定期搜索；
- SFR 空闲信标。

开发者通过调试链路更改它们（`tools/rfoundry_debug.py radio set ...`、`data settings ...`、`data ip-settings ...`、`snmp ...`）。电台会保留它们。漫游测量和信标设置在**菜单 > 扫描 > 漫游**中（[DMR](09-dmr.md#roaming)）。

没有设置菜单的构建（`CONFIG_UI_SETTINGS=n`）改为显示“请用 qdmr 设置”，并保留已存值。
